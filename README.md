# SmartTeachPen
> 版本：1.0.01 阿尼尔娜 Anirna

SmartTeachPen 是一款适用于班级大屏的屏幕批注工具，可以帮助教师便捷的进行快速批注，提高课堂时长利用率。

## ✨ 功能特性
- 🖌️ 屏幕画笔批注，多颜色画笔、橡皮擦
- 🖥️ 全局悬浮工具栏，授课时随时调出
- ⚙️ 完整设置面板，内置「重新运行欢迎向导」选项
- 🧩 插件系统基底，兼容类似 ClassIsland 的插件开发逻辑
- 🌓 亮色/暗色主题切换，跟随系统主题
- 📦 双发布渠道：正式版 / 预览版
